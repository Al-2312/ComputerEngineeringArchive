# Systems Engineering & Computer Architecture Archive

repository containing low-level implementations, algorithmic data structures, and systems architecture projects completed throughout my Computer Engineering studies. 

This collection emphasizes hardware-software integration, memory management, and performance analysis across multiple architectures.

## Technical Domains & Implementations

* **Computer Architecture & Assembly:** Implementations of processor instruction sets, memory hierarchies, and low-level execution logic utilizing MIPS Assembly.
* **Systems & Operating Systems Programming:** Core concepts in memory allocation, and process management implemented in C++.
* **Algorithmic Complexity:** High-performance data structures and algorithm analysis developed in C++.
* **Embedded Logic & Automation:** Hardware interfacing, digital logic design, and automated testing pipelines utilizing VHDL.
